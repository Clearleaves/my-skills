# 生成提示词与组合

每次重新读取实际参考图片。以下是结构模板，不是要求每次完全相同的固定场景。

## 根据人物选择风格

- **普通人物**：自然生活摄影，茶室、书房、庭院或符合其生活设定的场景，背景适度虚化，普通柔光。不加金色光环、神殿或神化特效。
- **关羽等神将／神话祝福角色**：庄严、安定、祥和；优先中式金色殿堂、金色立柱、雕花殿门与暖金灯火，可加入柔和金色圆环。保留该角色原有面容、妆容、头饰和标志服饰，不能把金色背景理解成要把人物皮肤或衣服全部变金。
- 普通古装人物、白须老者不因此自动归为神话角色；以用户说明和实际参考为准。用户另有风格要求时遵从本次要求。

## 通用模板

```text
Use case: identity-preserve。
以参考图中的同一位成年人物为身份参考，生成一张新的自然真实生活照片。
保留其脸型、五官、年龄、发型、胡须、体型及气质，不变成另一个人。
服饰：[颜色、款式、纹样，遵守用户最新的变化幅度要求]。
动作：[自然、适合该人物的手势或坐站姿态]。
环境：[与其他编号不同的场景和布置]。
镜头：[近景/中景/四分之三身，拍摄角度和画面位置]。
光线：[自然柔光]，背景适度虚化，人物脸和手自然清楚。
竖版9:16，普通手机照片画质即可，不追求超清或过度锐化。
无文字、无水印、手指正常；单张照片，不拼图。
```

老者人物的组合示例（仅当账号参考确为此类人物时使用，其他人物需在其自身设定内重新设计）：

| 编号 | 镜头与动作 | 服饰与环境 |
| --- | --- | --- |
| 01 | 胸部近景，轻握白瓷杯 | 浅灰蓝中式衬衣，明亮窗边茶室 |
| 02 | 腰腿中景，坐藤椅，双手交叠 | 米色中式外套，竹丛庭院廊下 |
| 03 | 到膝盖远景，站姿单手扶桌 | 深棕长衫，木质书房 |
| 04 | 胸腹中近景，轻摊掌讲述 | 墨绿棉麻上衣，竹帘茶室 |
| 05 | 腰腿中景，手搭石桌 | 浅灰中式外套，月洞门庭院 |
| 06 | 胸部近景，捧一本合上的薄书 | 暖棕中式衬衣，简洁家居书房 |
| 07 | 到膝盖远景，双手松松交握 | 藏蓝长衫，中式庭院廊下 |
| 08 | 腰部中近景，抬食指聊天 | 燕麦米色上衣，圆窗茶室 |

首次样图优先选01、02、03，让用户对比镜头距离和动作范围；认可后保留这3张，仅生成04～08。若用户改变要求，只重做受影响的编号。

若要求小改服饰，将模板中的服饰段替换为：保持参考图主色、材质、立领盘扣结构和主要纹样，只微调领口、袖口或同色盘扣；禁止大幅换色。若要求小改动作，保持坐站姿态，仅改变手掌朝向、抬手高度或轻微头部角度。

## 关羽祝福风格模板（已认可）

```text
Use case: identity-preserve。
以参考图中同一位成年男性关羽造型为身份参考，生成真实角色摄影画面。
保留同一张脸、红脸妆、浓黑上扬长眉、黑色长胡须、深绿头巾与金色额饰、深绿金边战袍及黑金铠甲。
人物庄重威严而平和，目光正对镜头，嘴唇自然微合，胸腹以上中近景；右手在胸腹前自然轻摊掌，如稳重送上祝福，不指责镜头。
背景为庄严恢宏的中式金色殿堂，对称金色立柱、远处雕花殿门、暖金色灯火；环境适度虚化，不盖过人物。
头部后方外侧有一圈柔和完整的圆形金色光环，与头巾分离，不穿过脸或身体；少量细小金色光点，整体庄严、安定、祥和。
脸与双手自然清楚，暖金轮廓光，保留原有红脸妆；竖版9:16，普通照片画质即可。
无文字、无水印、无拼图、无多余人物；不使用夸张爆炸光效。
```

后续8张可变化金色殿堂的立柱、殿门、回廊、帷幔、灯火布局，以及近中远景、抬手或双手交握等稳重动作。光环保持柔和，不能遮挡角色标志头饰；用户要求少些特效时优先减弱辉光和粒子。其他神话角色仅复用环境方向，必须替换身份约束为其自身特征，不能套用关羽红脸、头巾与铠甲。
