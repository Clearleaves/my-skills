# 生成提示词与组合

每次重新读取实际参考图片。以下是结构模板，不是要求每次完全相同的固定场景。

```text
Use case: identity-preserve。
以参考图中的同一位成年人物为身份参考，生成一张新的自然真实生活照片。
保留其脸型、五官、年龄、发型、胡须、体型及气质，不变成另一个人。
服饰：[颜色、款式、纹样，遵守用户最新的变化幅度要求]。
动作：[自然、适合该人物的手势或坐站姿态]。
环境：[与其他编号不同的场景和布置]。
镜头：[近景/中景/四分之三身，拍摄角度和画面位置]。
光线：[自然柔光]，背景适度虚化，人物脸和手自然清楚。
竖版9:16，普通手机照片画质即可，不追求超清或过度锐化。
无文字、无水印、手指正常；单张照片，不拼图。
```

老者人物的组合示例（仅当账号参考确为此类人物时使用，其他人物需在其自身设定内重新设计）：

| 编号 | 镜头与动作 | 服饰与环境 |
| --- | --- | --- |
| 01 | 胸部近景，轻握白瓷杯 | 浅灰蓝中式衬衣，明亮窗边茶室 |
| 02 | 腰腿中景，坐藤椅，双手交叠 | 米色中式外套，竹丛庭院廊下 |
| 03 | 到膝盖远景，站姿单手扶桌 | 深棕长衫，木质书房 |
| 04 | 胸腹中近景，轻摊掌讲述 | 墨绿棉麻上衣，竹帘茶室 |
| 05 | 腰腿中景，手搭石桌 | 浅灰中式外套，月洞门庭院 |
| 06 | 胸部近景，捧一本合上的薄书 | 暖棕中式衬衣，简洁家居书房 |
| 07 | 到膝盖远景，双手松松交握 | 藏蓝长衫，中式庭院廊下 |
| 08 | 腰部中近景，抬食指聊天 | 燕麦米色上衣，圆窗茶室 |

首次样图优先选01、02、03，让用户对比镜头距离和动作范围；认可后保留这3张，仅生成04～08。若用户改变要求，只重做受影响的编号。

若要求小改服饰，将模板中的服饰段替换为：保持参考图主色、材质、立领盘扣结构和主要纹样，只微调领口、袖口或同色盘扣；禁止大幅换色。若要求小改动作，保持坐站姿态，仅改变手掌朝向、抬手高度或轻微头部角度。
