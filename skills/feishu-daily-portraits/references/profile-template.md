# 账号配置模板

仓库只保存可复用流程。用户的飞书链接、Base token、表ID和个人账号映射不写入此文件，也不提交到公开仓库。

调用时优先使用用户给的链接；用户希望复用配置时，可在本机建立 `references/accounts.local.md`（仓库已忽略 `*.local.md`），内容建议包括：

- 多维表格名称和链接
- 用户时区
- 账号名称到数据表名称或ID的映射
- 使用日期、人物形象、备注字段名称
- 每个账号的人物特征、已认可风格和允许变化范围

不填写认证凭据。资源ID只是定位入口，每次操作前仍需读取并核验名称、字段和记录。

每个账号的参考人物可能完全不同。例如老者、关羽或其他角色，必须分别查看自己的附件。保留具有身份识别意义的妆容、头饰、胡须、铠甲或其他标志；服装变化只能在该人物设定和用户要求范围内进行，不把老者茶室的范例直接套到其他角色。

音频按用户既有方案单独管理；本技能不复制或生成音频。若调用环境有临时CLI路径，也不要把机器特定绝对路径写入共享技能，优先使用可用的 `lark-cli`。
