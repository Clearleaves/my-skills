# zgh-wechat-short-draft

一个用于 Codex 的公众号创作 Skill：参考飞书中的作者素材，生成原创情感短文或手机竖版贴图，并保存到飞书草稿表。

## 两种模式

| 模式 | 文案 | 图片 | 交付 |
| --- | --- | --- | --- |
| 文章 | 最多300字，含标点 | 2.35:1无字横版 | 标题、正文、封面、可复制HTML及下载包 |
| 贴图 | 通常20–60字，建议不超过80字 | 9:16无字竖版 | 标题、独立配文、图片及下载包 |

每次创作先确定模式；用户已在当前请求中明确模式时直接按选择执行。文案注重原创、情感表达和完整收束；图片默认为不露正脸的成年女性，服装与姿态自然修饰身形。每条成稿都上传到用户指定的飞书草稿表并回读核验，不自动发布公众号。

## 安装

本技能属于 [my-skills](../../README.md) 集合。按仓库根目录安装说明，将 skills/zgh-wechat-short-draft/ 复制到 Codex 技能目录。不要把整个仓库复制成一个技能；已有同名技能时先备份并保留本地配置。

## 运行条件

本仓库提供工作流指令，不是独立运行的采集或出图程序。

- Codex 内置图片生成能力及 `imagegen` 技能。
- 已安装、认证的 `lark-cli`，以及 `lark-base` 技能和对目标表的权限。
- 文章排版使用 `zgh-space-wechat-layout`；该技能需在本地另行配置，本仓库未打包。
- 可选：`zgh-baokuan-title-generator` 与 `stop-slop`。缺少可选技能不影响基础创作；如果用户显式要求使用缺失技能，应先说明。

首次使用提供素材表和草稿表的飞书链接。配置方法见 [飞书目标配置](references/feishu-target.md)。仓库不包含个人飞书定位信息、认证凭证、作者原文或生成图片。

## 使用示例

```text
使用 $zgh-wechat-short-draft，参考我指定的素材表，做一条贴图。
图片不要有字，配文单独保存到我的草稿。
```

```text
使用 $zgh-wechat-short-draft，生成一篇文章。
参考素材表中的表达特点，正文不超过300字，结尾要完整。
```
